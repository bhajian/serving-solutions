# Dynamo studies

[Home](../../../README.md) › [Tracks](../../README.md) › [NVIDIA Dynamo](../README.md) › Studies

Each completed study keeps everything in one folder: `REPORT.md` (protocol and results),
`README.md` (archive and data guide), the driver script, the analysis notebook, the run
folders the notebook reads, and `ARCHIVE-MANIFEST.sha256` for the raw evidence published as
release archives ([ARCHIVE.md](ARCHIVE.md)). Restore raw files with
`python tools/archive_results.py restore --from <dir>`.
